# Jedi — Systems Map

All game systems organized by build priority. Tier 1 must be complete before any Tier 2 work begins.

---

## Tier 1 — Core (game does not function without these)

- [ ] Player Character System
- [ ] Combat System
- [ ] Health and Death System
- [ ] Enemy AI
- [ ] Force Powers
- [ ] Game State (pause, save, load, menus)

---

## Tier 2 — Secondary (game is shallow without these)

- [ ] Progression System (XP, leveling, ability choices)
- [ ] World Design (level structure, traversal, fast travel)
- [ ] Stealth System
- [ ] Enemy Variety (Stormtroopers, Inquisitors, elites, bosses)
- [ ] Inventory and Items
- [ ] Equipment System (mechanical effects, not cosmetic)
- [ ] Narrative System

---

## Tier 3 — Polish (game feels complete with these)

- [ ] UI and HUD
- [ ] Audio System
- [ ] Game Feel (hit stop, screen shake, VFX, rumble)
- [ ] Animation System
- [ ] Environment Art
- [ ] Character Art

---

## Tier 4 — Stretch (separates good from great)

- [ ] Map and Exploration (holographic map, metroidvania unlocks)
- [ ] Companion System
- [ ] Accessibility and Settings
